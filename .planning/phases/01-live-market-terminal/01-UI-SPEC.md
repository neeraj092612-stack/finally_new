# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Sources: `01-CONTEXT.md` decisions D-01..D-23 (locked, cited as `D-nn`), `planning/PLAN.md` §2, §8, §10, `REQUIREMENTS.md` UI-01, UI-02, UI-04, DEP-03. Items marked **(default)** were not decided upstream and are set here as prescriptive defaults.

Scope: the Phase 1 page is read-only. Live now: header, watchlist, main chart. Placeholders only: trade bar, heatmap, P&L chart, positions table, chat (D-02).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (hand-built Tailwind components) |
| Preset | not applicable |
| Component library | none |
| Icon library | none: inline SVG only (triangle markers, chevron). No icon package in Phase 1. |
| Font | Numerals, tickers, prices, table cells: JetBrains Mono (`@fontsource/jetbrains-mono`, weights 400 and 600 only, bundled so the image needs no CDN). Labels, titles, empty-state copy: system sans stack `ui-sans-serif, system-ui, "Segoe UI", Roboto, sans-serif`. |

Why `Tool: none` **(default)**: shadcn defaults (rounded cards, shadows, light/neutral tokens) conflict with D-03 (square terminal chrome, 1px borders, no shadows), and the stack is fixed by PLAN.md §10 (Tailwind + hand-rolled SVG + Lightweight Charts). The shadcn initialization prompt was not put to the user because the subagent could not ask interactively; the orchestrator may re-offer it.

Stack pins to verify at install (npm registry, 2026-10-20): `next` 16.x static export (`output: 'export'`), `tailwindcss` 4.x (CSS-first `@theme` tokens; if v3 is installed, put the same tokens under `theme.extend` in `tailwind.config`), `lightweight-charts` 5.x (v5 API only: `chart.addSeries(AreaSeries, opts)`; never `addAreaSeries`).

## Layout and Panels (D-01..D-04)

Desktop (viewport width >= 1200px): `100vh` app, no page scroll, 4px outer padding and 4px gap between panels. Panels scroll internally. Minimum supported height 720px (below that the page scrolls).

```
HEADER (48px, full width)
+------------+-----------------------------+------------+
| WATCHLIST  | CHART · AAPL (flex, min 280)| CHAT       |
| (flex)     +--------------+--------------+ (full col) |
|            | HEATMAP 220  | P&L 220      |            |
+------------+--------------+--------------+            |
| TRADE (96) | POSITIONS (200)             |            |
+------------+-----------------------------+------------+
   352px            flex (min 528)              320px
```

- Left column: WATCHLIST fills the remaining height (min 332px = title 28 + column header 24 + 10 rows x 28); TRADE placeholder pinned beneath at 96px.
- Center column: chart takes the remaining height; heatmap and P&L side by side at 50% each, 220px tall; positions 200px.
- Right column: CHAT panel full height.
- Panel chrome (D-03): 28px title bar on `surface`, label typography, text `muted`; 1px `border` on all panels; panel body on `bg`; 0 border-radius; no shadows.

Tablet (width < 1200px) (D-04): single column in this order: header, watchlist (10 rows visible, no inner scroll), chart (height 320px), heatmap, P&L, positions, trade placeholder, chat. Heatmap and P&L stack (each full width, 220px). Chat panel is collapsible: collapsed by default, a 28px title-bar button toggles it (label "Show chat" / "Hide chat" with a chevron SVG, 16px). Page scrolls vertically. Functional only, no further tuning.

Header contents, left to right (48px, `surface`, bottom 1px border):
1. Wordmark `FinAlly` in Heading style: "Fin" in `text`, "Ally" in `accent`.
2. Group `TOTAL VALUE` (Label caption above, Display value below): `$10,000.00` format.
3. Group `CASH` (Label caption, Heading value).
4. Right-aligned: connection dot (8px) + Label text (see Connection indicator).
Groups separated by `lg` (24px). On tablet the captions stay, groups may wrap to a second line.

## Watchlist Panel (UI-02, D-05..D-13)

Title bar: `WATCHLIST`. Column-header row (24px, `surface`, Label style): `TICKER`, `TREND`, `PRICE`, `DAY %`. Numeric headers right-aligned.

Row (28px, single line, 8px horizontal padding, 8px column gaps), columns in order (D-09):

| Column | Width | Content |
|--------|-------|---------|
| Ticker | 64px, left | Heading style (14px/600), `text`; truncate with ellipsis, full symbol in `title` attribute |
| Sparkline | flex (about 80px) | SVG polyline, see Sparkline |
| Price | 88px, right | Body mono, tabular; `1,234.56` format (2 dp, thousands separators, no currency symbol); followed by 8px triangle marker (see below) |
| Day % | 72px, right | Body mono; signed, 2 dp: `+0.65%`, `-0.07%`, `0.00%` |

Price cell behavior:
- Flash (D-05): on every received price that differs from the previously displayed price, the price cell background animates from the flash tint to transparent over 500ms, `ease-out`. Implement as a CSS keyframe animation on a class (`flash-up` / `flash-down`) re-triggered per change (force restart via a changing React `key` or class toggle with reflow). Flash applies to the price cell only, never the whole row, header total, or chart strip.
- Marker (D-07): 8px SVG triangle after the price, `up` (▲) or `down` (▼), showing the last non-flat tick direction. A flat tick keeps the previous marker. No marker until the first change after page load. Driven by comparing client-side successive prices and the stream `direction` field (D-06 makes the backend report flat only on a true no-change).
- Price text color stays `text`; only the flash and marker carry direction.
- No price yet (`price` null): render `—` in `muted` for Price and Day %, empty sparkline baseline (D-13). Never render `0`.
- Stale/not live: when the connection state is not OPEN, price text switches to `muted` and flash is suppressed.

Day % (D-13, D-18): colored `up` / `down` by sign, `muted` at exactly 0.00. Initial value from `GET /api/watchlist` `day_change_percent`. To stay live between fetches, derive the baseline price once per ticker as `price_at_fetch / (1 + day_change_percent/100)` and recompute `(price - baseline) / baseline * 100` on every SSE tick. If a ticker's `day_change_percent` was null at fetch, refetch `/api/watchlist` once (debounced 1s) when its first SSE price arrives.

Selection (D-12, D-15): the selected row has a 4px `accent` bar on its left edge and `surface-2` background. Click or Enter/Space selects. First watchlist entry is selected on load; selection is not persisted. Hover (unselected): `surface-2` background, cursor pointer, 100ms transition.

Keyboard and accessibility **(default)**: the list is `role="listbox"` with rows `role="option"`, `aria-selected` on the selected row; roving tabindex; ArrowUp/ArrowDown move selection and the chart follows; focus ring 2px `primary`, inset. Row `aria-label` example: `AAPL, 190.24, up 0.65 percent`. Price cells are not `aria-live` (500ms updates would flood screen readers).

Sparkline (D-10, D-11):
- Hand-rolled SVG `<polyline>`, `viewBox="0 0 W 20"`, `preserveAspectRatio="none"`, `vector-effect: non-scaling-stroke`, stroke 1.5px, `stroke-linejoin: round`, no fill.
- Data: ticks since page load, rolling window of at most the last 5 minutes and at most 600 points; drop oldest beyond either limit.
- Scaling: x spreads the current points across the full width (so it fills in progressively from page load); y auto-scales to the window min/max with 2px vertical padding; if min equals max, draw a horizontal line at mid-height.
- Fewer than 2 points: draw a 1px dashed `border`-color baseline at mid-height.
- Color (D-11): `up` if last point is above first, `down` if below, `muted` if equal.

## Main Chart Panel (UI-04, D-14..D-17)

Title bar: `CHART · {TICKER}` (Label style; the ticker part in `accent`).

Chart strip (40px, `bg`, below title bar), left to right: ticker symbol (Heading), live price (Display, mono, no flash), change since page load as `+1.24 (+0.65%)` (Body, `up`/`down`/`muted` by sign, abs first then percent), then session `H 191.80   L 189.90` (Body, `muted` labels `H`/`L`, `text` values). "Session" and "since page load" both mean since this page was opened; high/low and change are computed from the buffered ticks (first buffered price is the baseline). Before any tick, show `—`.

Chart (Lightweight Charts v5, canvas; one chart instance created once in a client-only component, destroyed with `chart.remove()` on unmount; `next/dynamic(..., { ssr: false })` and `'use client'`; `autoSize: true`):
- Series: `chart.addSeries(AreaSeries, {...})` with `lineColor: '#209dd7'`, `lineWidth: 2`, `topColor: 'rgba(32,157,215,0.28)'`, `bottomColor: 'rgba(32,157,215,0)'`, `lastValueVisible: true`, `priceLineVisible: true`, `priceLineColor: '#209dd7'`, `priceFormat: { type: 'price', precision: 2, minMove: 0.01 }`.
- Layout: `background: transparent` (shows `bg`), `textColor: '#8b949e'`, `fontSize: 11`, `fontFamily` the mono stack; grid lines `#21262d` both axes; both axis borders `#30363d`.
- Crosshair (D-16): `CrosshairMode.Normal`, lines `#484f58` dashed, price label on the right scale and time label on the bottom axis.
- Time scale (D-17): `timeVisible: true`, `secondsVisible: true`, `rightOffset: 4`; scroll and zoom enabled (library defaults); `fitContent()` is called when the selected ticker changes. No programmatic re-fit on every tick, so a user who has scrolled or zoomed is not yanked back.
- Data: the app keeps a per-ticker tick buffer for all watched tickers from page load (not just the selected one), safety cap 50,000 points per ticker **(default)**. Chart time = `Math.floor(tick.timestamp)` (SSE `timestamp` is Unix seconds float; UTCTimestamp must be integer seconds and strictly ascending). Use `series.setData(buffer)` on ticker switch and `series.update(point)` per tick; two ticks in the same second collapse to the latest value (library replaces when time equals last). Ignore ticks with a time earlier than the last charted time.
- Switching tickers (row click or arrow key): title, strip and series swap in the same frame; no animation.
- Empty selected buffer: overlay centered text (see Copywriting) over the empty chart area.

## Connection Indicator (UI-01, D-19)

Dot (8px circle) plus Label text, in the header, `role="status"` with `aria-live="polite"` so a change is announced once.

| `EventSource.readyState` | Dot | Label | Notes |
|--------------------------|-----|-------|-------|
| OPEN (1) | `up` | `LIVE` | static dot |
| CONNECTING (0) | `warn` | `RECONNECTING` (`CONNECTING` on first load, before the first OPEN) | dot pulses opacity 1 to 0.4 over 1s, infinite |
| CLOSED (2) | `down` | `OFFLINE` | static dot; client recreates the `EventSource` after 2s, backing off to a 10s cap **(default)** |

`title` on the group: `Price stream connected` / `Price stream reconnecting` / `Price stream disconnected. Retrying.`

## Data Binding (what drives what)

| UI | Source |
|----|--------|
| Watchlist tickers and order | `GET /api/watchlist` on load (ordered by `added_at`) |
| Live price, direction, timestamp | `EventSource('/api/stream/prices')`; events carry all tickers keyed by ticker; ignore tickers not on the watchlist |
| Day % | see Watchlist Panel |
| Header cash, total value | `GET /api/portfolio` on load; total value live = `cash_balance + sum(quantity x live price)` (positions are empty in Phase 1, so it equals cash). Unrealized P&L is not shown in Phase 1 **(default)** |
| Connection state | `EventSource.readyState` via `onopen` / `onerror` handlers |

One shared price store (single `EventSource` for the whole app) feeds header, watchlist and chart. Money formats: header uses `$10,000.00` (`Intl.NumberFormat('en-US', currency USD)`); prices use 2 dp without symbol; negative numbers use a leading ASCII `-`.

## UI Considerations

Applicable state considerations resolved: 14 covered, 2 backstop, 1 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | watchlist list-collection | ✅ covered | Zero tickers renders the documented `No tickers watched` empty state (copy in Copywriting Contract) |
| loading | watchlist list-collection | ✅ covered | While the first watchlist fetch is in flight, 10 skeleton rows render; the layout height does not change when rows arrive |
| error | watchlist list-collection | ✅ covered | A failed watchlist fetch renders the documented error heading, body and a `Retry` action |
| partial | watchlist rows with null price | ✅ covered | Rows without a price show `—` for Price and Day % and an empty sparkline baseline, never `0` |
| zero-one-many | watchlist list-collection | ✅ covered | Zero shows the empty state; one or ten rows use the same 28px row layout with no plural copy |
| overflow | watchlist list-collection | ✅ covered | More rows than fit make the list body scroll inside the panel; the title bar and column header stay fixed |
| long-text | watchlist ticker cell | ✅ covered | Symbols longer than the 64px cell truncate with an ellipsis and expose the full symbol in `title` |
| loading | main chart | ✅ covered | With an empty buffer for the selected ticker the chart shows `Waiting for the first price…` |
| empty | main chart | ✅ covered | With no selectable ticker the chart shows `Select a ticker to see its chart.` |
| error | connection indicator | ✅ covered | CONNECTING shows yellow `RECONNECTING`, CLOSED shows red `OFFLINE` with automatic re-open; prices render `muted` and flash is suppressed while not OPEN |
| error | header portfolio values | ✅ covered | A failed `GET /api/portfolio` shows `—` with an explanatory `title`; the page stays usable |
| empty | placeholder panels | ✅ covered | Each deferred panel renders its titled empty state so the grid does not shift in later phases |
| nav | tablet chat toggle | ✅ covered | Below 1200px the chat panel is collapsed by default and toggled by a labeled title-bar button with `aria-expanded` |
| partial | sparkline with fewer than 2 points or a flat series | ✅ covered | Fewer than 2 points draws a dashed baseline; equal min and max draws a flat `muted` line at mid-height |
| populated | chart and sparklines over a long session | 🧪 backstop | Held-out UI-state test: after 50,000 buffered ticks per ticker the oldest are dropped and the chart still updates without lag |
| overflow | header total value at large magnitudes | 🧪 backstop | Held-out visual test: `$1,000,000.00` at Display size fits the header group without wrapping or truncation |
| partial | hidden browser tab (throttled rendering) | ⚠ unresolved | Planner assumes no special handling: buffers keep filling from `EventSource`, flash animations may be skipped while hidden |

Outside market hours in Massive mode prices are static, so there is no flash and sparklines are flat `muted` lines; this is expected (PLAN §13.2 item 14), not a defect.
