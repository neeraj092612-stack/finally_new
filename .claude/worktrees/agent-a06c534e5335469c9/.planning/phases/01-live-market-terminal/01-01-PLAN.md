<objective>
Walking-skeleton tracer for the server: one `create_app()` process seeds SQLite, starts the simulator with the seeded watchlist and streams those prices over SSE, serves the static export at `/`, and answers `/api/health` (SQLite seed -> lifespan -> simulator -> PriceCache -> `/api/stream/prices`, plus the guarded static mount).

Purpose: proves every backend layer the phase touches with a real uvicorn process before any expansion work (market fixes, REST endpoints, Docker) builds on it. Implements D-21 (lifespan startup order, DB_PATH).
Output: `backend/app/{main,config}.py`, `backend/app/db/`, `backend/app/services/watchlist.py` (`list_tickers`), `backend/app/api/health.py`, the subprocess smoke test.
</objective>

## Phase Goal

ROADMAP goal (verbatim; it is not written in As a / I want to / so that form, so no story is invented here — run `/gsd-mvp-phase 1` to reframe it if wanted): User starts the app with one script, opens http://localhost:8000, and watches the 10 default tickers stream live with flashing prices, sparklines and a main chart, next to a $10,000 portfolio.

This plan is the server leg of the Walking Skeleton (see `SKELETON.md` in this phase directory). The market fixes (01-03) and the frontend toolchain (01-02) run in parallel with it; the REST endpoints (01-06), stream-router and Massive fixes (01-07) and error envelope (01-09) expand it; plans 01-11 and 01-13 close the loop through the container and start scripts.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> FastAPI (localhost) | Unauthenticated HTTP requests to /api/* and / ; single-user by design |
| process env -> Settings | DB_PATH and STATIC_DIR come from the operator's environment, never from requests |
| FastAPI -> SQLite file | Queries built by the app against the DB file in the volume |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | StaticFiles mount at / (path traversal) | medium | mitigate | Serve the export only through Starlette `StaticFiles(directory, html=True)` (safe-path resolution), mounted after every API router; no hand-rolled file route |
| T-01-02 | Tampering | SQL in db/ and services/watchlist.py | medium | mitigate | Every statement uses `?` placeholders; `USER_ID` is a module constant; no request data reaches SQL in this plan |
| T-01-03 | Information disclosure | /api/health, /api/stream/prices | low | accept | Data is simulated prices for a single local user; loopback-only port binding is enforced by the start scripts in plan 01-13 |
| T-01-04 | Denial of service | SSE generator per client | low | accept | Single user; each generator sleeps 500 ms between polls; one uvicorn worker shares one cache |
| T-01-05 | Tampering | DB_PATH / STATIC_DIR env values | low | accept | Operator-controlled configuration only; values are stripped and never derived from HTTP input |
</threat_model>
