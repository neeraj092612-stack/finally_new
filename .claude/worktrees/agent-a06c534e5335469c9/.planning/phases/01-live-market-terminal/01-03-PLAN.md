<objective>
Fix the market data core so every real price move is visible and every ticker carries a day-change baseline: the D-18 simulator baseline (`reference_price`, `day_change_percent`), the D-06 raw-price direction fix, and the MKT-04 pre-start ticker queue.

Purpose: without D-06 most 500ms simulator ticks serialize as "flat", so the watchlist would rarely flash (UI-02); without the baseline the watchlist and SSE cannot show Day % (MKT-05); without MKT-04 tickers added before start are silently dropped. Runs in parallel with the server tracer (01-01) because it touches only `backend/app/market/` internals behind unchanged signatures. Implements D-06 and D-18 (simulator half).
Output: updated `models.py`, `cache.py`, `simulator.py` and their tests.
</objective>

```python
@dataclass(frozen=True, slots=True)
class PriceUpdate:
    ticker: str; price: float; previous_price: float; timestamp: float = field(default_factory=time.time)
    change / change_percent / direction  # @property, computed from the rounded price fields today

class PriceCache:
    def update(self, ticker: str, price: float, timestamp: float | None = None) -> PriceUpdate  # rounds to 2 dp; `timestamp or time.time()` treats 0.0 as missing

class GBMSimulator:  def step(self) -> dict[str, float]  # rounds to 2 dp today (Pitfall 1)
class SimulatorDataSource:  async start(tickers), add_ticker(t)  # add before start is a silent no-op today
```
