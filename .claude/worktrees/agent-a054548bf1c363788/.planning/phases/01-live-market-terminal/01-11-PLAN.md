## Verification safety rules (user decision OQ-5, mandatory for every command in this plan)

- Never run `docker volume rm finally-data`, never mount `finally-data`, never `docker rmi finally` or `docker image prune`. Rebuilding the `finally` tag is allowed (the old image stays on disk, untagged).
- All container checks use container `finally-phase1-test`, volume `finally-data-phase1-test` and host port 18000. Removing that test container and test volume is allowed.
- Use `MSYS_NO_PATHCONV=1` (export it) for docker commands in Git Bash so `/app/db` is not rewritten into a Windows path.
- Never read, print or copy the repo-root `.env`. Only stop processes and containers this plan started.
