<objective>
Build the shared client data layer: one SSE price store (ticks, flash sequences, markers, session stats, buffers, connection state with reconnect), the connection indicator component (D-19), the number formatters and the same-origin API fetchers.

Purpose: every live panel reads prices through this one store, so the page opens exactly one EventSource and every panel agrees on flash and Day % rules. The header (01-08), watchlist (01-10) and chart (01-14) plans consume it. Implements D-19, D-20 (browser-only history) and the OQ-1 resolution (flash driven by stream direction, de-duplicated by timestamp); provides the marker state for D-07.
Output: `frontend/src/lib/{types,priceStore,format,api}.ts`, `ConnectionIndicator`, tests.
</objective>

## Phase Goal

ROADMAP goal (verbatim, not in user-story form; see plan 01-01): User starts the app with one script, opens http://localhost:8000, and watches the 10 default tickers stream live with flashing prices, sparklines and a main chart, next to a $10,000 portfolio.

## UI Considerations (from 01-UI-SPEC.md) handled in this plan

- error / connection indicator: covered (indicator component and reconnect states here; the header placement is plan 01-08; muted prices and suppressed flash are plan 01-10).
- partial / hidden browser tab: dismissed. Reason (UI-SPEC): no special handling needed; EventSource keeps filling the buffers while hidden, skipped flashes are harmless and the chart is current on return.
