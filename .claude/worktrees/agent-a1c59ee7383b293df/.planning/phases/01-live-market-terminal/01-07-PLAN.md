<objective>
Fix the two remaining market-package defects: the module-level SSE router that registers duplicate routes (MKT-03) and the Massive snapshot parsing that drops every price (MKT-01), with the previous-close day-change baseline in Massive mode (MKT-05, D-18) and fail-soft polling.

Purpose: one stream route per app keeps every app instance bound to its own cache (PLAT-06); Massive mode currently reads a trade attribute that does not exist, so a user with a key would see no prices at all. Implements D-18 (Massive half) and the OQ-3 resolution (no key: prove with real models, fail soft).
Output: rewritten `stream.py` factory, `parse_snapshot` and the hardened poller in `massive_client.py`, tests.
</objective>
